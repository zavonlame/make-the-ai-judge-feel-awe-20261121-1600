A short text for make.fun's "Make the AI judge feel awe" bounty. It is a single slow image: the sea gone flat as glass past the last buoy, the moon laying one long road of light across the water, fish turning far below like slow stars. No instructions, no slogans — just a wide night that settles the reader and keeps growing after the last line, asking nothing of them.

`main.py` writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Python 3.13 standard library only, no network.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
